# Merchivra ERP

> Open-source commerce operations platform. / 开源跨境电商 ERP 平台。

This repository is under active initialization. Project goals: Amazon Seller operations, self-hosting, modular architecture, and extensible marketplace adapters.

项目初始化进行中：先完成 MVP 需求、技术架构、开发任务与基础工程，再逐步接入 Amazon SP-API。

**Important:** Do not commit Amazon credentials, refresh tokens, customer PII, or production exports.

## Design documentation / 项目设计文档

Before implementing business features, review the **[Merchivra documentation center](docs/README.md)**. It includes the MVP PRD, business flows, architecture and ER diagrams, Amazon integration constraints, security, test plan and open decisions.

目前优先推进文档和图纸评审，设计稿仍处于 Draft/Proposed 阶段，**不代表系统已经实现**。完整清单见 [图纸目录](docs/diagrams/index.md) 和 [待确认资料](docs/requirements/decision-questions.md)。
