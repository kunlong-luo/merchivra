# UX-REQ-001 · 用户角色、任务与权限

## 用户画像（工作角色，不描述特定个人）

| Persona | 最常做的事 | 最重要的问题 | P0 页面 |
|---|---|---|---|
| 店主/管理员 | 接入账户、管理成员、查看经营汇总 | 连接稳定？哪些 SKU 有风险？ | 总览、店铺、成员 |
| 运营专员 | 查询订单、Listing、FBA 库存 | 哪些商品缺货？同步是否最新？ | 订单、商品、库存、任务 |
| 财务人员 | 录成本、分类费用、对账 | 利润是否完整？费用来源？ | 成本、财务、利润 |
| 只读观察者 | 查看管理层授权的仪表盘 | 数据口径是什么？ | 只读报表 |
| 开源维护者 | 本地运行 Mock、阅读架构、提交 PR | 如何复现和测试？ | 文档、开发者工具（不接真实账号） |

## 初始 RBAC 草案

| 操作 | 租户管理员 | 运营 | 财务 | 只读 |
|---|---|---|---|---|
| 绑定/移除 Seller 连接 | 是 | 否 | 否 | 否 |
| 管理用户角色 | 是 | 否 | 否 | 否 |
| 查看商品/订单/库存 | 是 | 是 | 是 | 是（受授权范围限制） |
| 手动触发同步 | 是 | 是 | 否 | 否 |
| 修改 SKU 映射 | 是 | 是 | 否 | 否 |
| 录入成本/费用分类 | 是 | 否 | 是 | 否 |
| 查看利润 | 是 | 可配置 | 是 | 可配置 |
| 导出数据 | 是 | 可配置 | 可配置 | 默认否 |
| 查看/管理密钥 | 仅可管理连接，不可读原始密钥 | 否 | 否 | 否 |

**规则**：默认拒绝、服务端强制校验、后台任务继承明确的租户作用域，任何角色都不应获得明文 refresh token 读取权限。

## 关键用户任务

- 管理员：10 分钟内理解 Mock 部署及账号配置步骤（目标，不是已验证数字）。
- 运营：2–3 次点击内从低库存告警定位到 Seller SKU/Listing。
- 财务：从某笔利润汇总追溯到商品成本版本与财务来源事件。
