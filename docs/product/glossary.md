# GLOSSARY-001 · 业务术语与数据语义

| 术语 | 定义 | 禁止混用 |
|---|---|---|
| Tenant | ERP 中拥有隔离数据空间的组织 | 与 Seller Account 不是同一实体 |
| Seller Account | 一个亚马逊卖家账户/授权主体 | 不等于 Marketplace |
| Marketplace | Amazon 站点/市场，例如 US/UK | 不等于 API 区域 |
| Region | SP-API 接入区域，如 NA、EU、FE | 不等于具体站点 |
| Internal SKU | Merchivra 维护的内部商品变体编码 | 不等于卖家 SKU |
| Seller SKU | 卖家在特定账户/站点使用的可销售 SKU | 不等于 ASIN |
| ASIN | 亚马逊商品目录标识 | 不等于 ERP 商品主键 |
| FNSKU | FBA 库存识别标识 | 不作为跨所有站点统一主键 |
| Listing | 某账户在某 Marketplace 的商品售卖记录 | 不是全局产品 |
| FBA | Fulfillment by Amazon，亚马逊履约 | 不等于 FBM |
| FBM / MFN | 卖家自行履约 | 不应套用 FBA 库存规则 |
| Snapshot | 来源系统某时间点的库存观测值 | 不是增减流水 |
| Ledger | 不可变的数量或金额变动流水 | 不等于最新快照 |
| Source event | 平台原始事件/交易记录 | 可重复接收，需幂等 |
| 商品毛利参考值 | 折后商品销售额减去对应商品成本，尚未扣平台销售与物流履约等费用 | 不等于完整经营利润 |
| 预估订单贡献额 | 商品毛利参考值进一步扣除已明确的订单相关销售/履约费用的参考指标；必须标注费用范围 | 不得叫作已实现净利润 |
| 未分配财务事件 | 已保存源财务事实、但缺少充分订单/SKU 关联证据 | 不自动扣到任意商品 |
| Estimate | 基于当前已知成本/费用计算的估算 | 不等于已入账利润 |
| Posted | 已由平台确认并进入事件流水的金额 | 不等于银行到账 |
| Settled | 与平台结算/支付批次关联的金额 | 不等于营收 |
| ACOS / TACOS | 广告投入与归因或总销售额的比例 | 广告模块 P1，指标口径需单独确认 |
| Checkpoint | 同步完成后安全持久化的位置/时间 | 不等于最后发起请求的时间 |

不确定的行业术语应在 PRD 冻结前与真实卖家确认，不应直接从已有商业 ERP 的界面名称推断。
