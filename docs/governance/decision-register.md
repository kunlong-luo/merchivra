## 如何提交决定

每个决定在 GitHub Issue 留下：决定编号、所选方案、业务动机、拒绝的备选、影响文件、负责人、日期和审查状态。设计文档里提到的默认方案**不能替代签字**。如果业务事实改变，创建新 ADR/决策版本而不是静默覆盖。
