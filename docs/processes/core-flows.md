# BIZ-001 · 核心业务流程图

**图纸性质：业务流程草案。** 所有外部平台数据处理都受 Amazon 许可、访问角色和业务范围约束。

## BIZ-01 店铺接入（私有应用优先）

```mermaid
flowchart TD
A["管理员创建租户"] --> B["选择 Mock 或自有 Amazon 店铺"]
B --> C{"接入模式"}
C -->|Mock| D["初始化虚构示例数据"]
C -->|真实店铺| E["确认应用注册/权限"]
E --> F["私有应用自授权或允许的授权流程"]
F --> G["服务端验证账户/站点"]
G --> H{"授权有效？"}
H -->|否| I["记录错误类型/指导修复"]
H -->|是| J["加密保存凭证引用"]
D --> K["创建初次同步任务"]
J --> K
K --> L["商品 → 订单 → 库存 → 财务"]
L --> M["显示同步状态与数据时间"]
I --> E
```

**控制点**：用户不能直接提交任意租户 ID；连接失败不得记录明文 Token；站点范围经授权校验。

## BIZ-02 商品从平台到 ERP 的映射

```mermaid
flowchart LR
A["Catalog / Listing 拉取"] --> B["平台标识标准化"]
B --> C{"Seller SKU 是否已有映射？"}
C -->|是| D["更新 Listing 快照"]
C -->|否| E["待映射商品队列"]
E --> F["运营选择已有内部 SKU 或创建新 SKU"]
F --> G["校验账户与站点唯一键"]
G --> D
D --> H["成本/订单/库存关联"]
```

**关键例外**：同一 ASIN 存在不同变体、包装、账号 Seller SKU；缺失映射不可静默归属错误的内部 SKU。

## BIZ-03 订单生命周期与退款

```mermaid
stateDiagram-v2
[*] --> Observed: 从平台获取
Observed --> Pending: 待履约
Observed --> Shipped: 已履约
Pending --> Shipped: 状态更新
Pending --> Cancelled: 取消
Shipped --> Refunded: 部分或全部退款
Cancelled --> [*]
Refunded --> [*]
Shipped --> [*]
note right of Observed
仅为 ERP 简化状态视图；
保留平台原始状态与时间
end note
```

**注意**：退款、付款、结算可在订单生命周期之外异步发生，不要求与订单状态严格同步。

## BIZ-04 FBA 库存对账

```mermaid
flowchart TD
A["获取带时间戳的 FBA 快照"] --> B["识别租户/账号/Marketplace/SKU"]
B --> C{"数据通过校验？"}
C -->|否| D["隔离错误记录并告警"]
C -->|是| E["保存历史快照"]
E --> F["按最新可靠观测计算当前库存"]
F --> G{"库存/数据时效阈值"}
G -->|低库存| H["提示补货风险"]
G -->|快照过期| I["提示数据过期"]
G -->|正常| J["更新仪表盘"]
```

**控制点**：快照覆盖当前观测，绝不当作增量库存流水；站点、所有权和状况分桶明确。

## BIZ-05 财务核对

```mermaid
flowchart TD
A["同步订单金额"] --> B["计算交易层预估收入"]
C["同步平台财务交易"] --> D["按交易类型归类费用/退款"]
E["加载 SKU 历史成本"] --> F["关联订单行"]
B --> G["预估毛利视图"]
D --> G
F --> G
G --> H{"费用/成本/汇率完整？"}
H -->|否| I["标记未完成或不可计算"]
H -->|是| J["显示预估口径与来源"]
D --> K["结算批次/回款核对（可用时）"]
K --> L["差异清单"]
```

**业务审批点**：业务负责人必须先确认计算口径，系统不能将广告未纳入的毛利命名为净利润。
