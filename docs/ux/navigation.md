## 4. 关键交互原则

- 一切聚合/报表均展示筛选范围、币种、同步水位和数据完整性。
- 未授权/空数据/同步失败要有不同状态，不显示误导性的零值。
- 订单详情默认不展示买家敏感信息；不同角色仅出现被授权操作。
- 危险操作（撤销连接、重新同步大时间段、修改成本）明确确认和审计。
- P1 再考虑移动端深度适配；MVP 首先保障桌面浏览器主业务路径。
