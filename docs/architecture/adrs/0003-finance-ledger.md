# ADR-0003 · 财务事件不可变 + 利润可重算

- **状态：Proposed**
- 日期：2026-10-30
- 决策：从 Amazon 获得的财务交易保留外部源 ID 和币种，避免修改已记录的原始财务事实；更正使用事件修正/冲销。利润按版本化规则计算，可追溯并可重算。

## 原因
Amazon 订单、财务事件与结算具有时间差，平台还可能追加退款、费用、调整。直接覆盖订单总额无法支持财务对账。

## 影响
保留原始业务键、发生/入账/结算时间；计算数据需要标记完整度、成本版本、汇率和计算版本。UI 必须区分「预估」与「已入账/结算」。

## 备选
仅存订单收入和固定费用：实现快，但会产生不可解释的经营利润。此方案不适合作为开源 ERP 的财务基础。

## 风险
存储增长、分类不全、回填影响；通过可重复聚合、分区/归档策略和对账差异报告管理。
