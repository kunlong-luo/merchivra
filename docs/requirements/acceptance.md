# QA-001 · MVP 验收方案（Given / When / Then）

**前提**：先运行 Fake/Mock provider，不要求真实 Amazon 权限；只有已被 Amazon 授权的试点数据才能用于真实接入测试。

| 用例 ID | 需求 | Given / When / Then |
|---|---|---|
| AC-01 | FR-SYS-01 | 租户 A 用户登录；访问租户 B 订单 ID；返回无权/不可见且没有记录泄露 |
| AC-02 | FR-SHOP-01 | 授权到期；执行同步；连接转失效且任务记录安全错误类型 |
| AC-03 | FR-CAT-02 | 1 个内部 SKU 对应两站点 Listing；导入后仍保持正确多对一映射 |
| AC-04 | FR-ORD-01 | 同一页订单连续同步 3 次；订单与订单项记录数、金额不变 |
| AC-05 | FR-ORD-01 | 首次同步在第 3 页网络故障；重新执行；从安全检查点/窗口补偿 |
| AC-06 | FR-ORD-03 | 先同步退款、后同步订单；退款最终匹配且金额未重复计入 |
| AC-07 | FR-INV-01 | 快照分别为 12、9 件；第二次同步后当前可售为 9，历史均保留 |
| AC-08 | FR-INV-02 | 库存快照过期；告警显示「数据过期」而不虚报断货 |
| AC-09 | FR-COST-01 | 商品成本在 6 月 1 日变更；5 月订单仍采用历史版本 |
| AC-10 | FR-FIN-01 | 相同财务事件从两个分页窗口出现；仅 1 次入账 |
| AC-11 | FR-FIN-02 | 缺少广告费/采购成本；报告明确「预估/不完整」，不显示已实现净利润 |
| AC-12 | FR-SYNC-01 | 模拟 HTTP 429 + Retry-After；任务退避后恢复，不无限重试 |
| AC-13 | FR-SYNC-02 | 同范围重复手动触发；任务不发生竞争重复写入 |
| AC-14 | FR-DASH-01 | USD 与 EUR 订单混合；未选汇率时不产生无标识合计 |
| AC-15 | FR-MOCK-01 | 全新克隆、无 SP-API 凭证；启动 Mock，能完成浏览操作 |
| AC-16 | FR-SYS-02 | 未登录访问私有 API；全部拒绝（健康检查例外且仅暴露必要信息） |
| AC-17 | NFR-SEC-02 | 提交和运行日志扫描；不存在 token、buyer PII、密钥和真实数据文件 |

## 各层测试

- 领域测试：SKU 映射、状态迁移、利润公式、成本有效区间。
- 适配器契约测试：相同 Mock 结构，Amazon DTO 映射不外泄到领域。
- DB 集成测试：Flyway migrations、唯一键、事务/锁、跨租户拒绝、恢复导入。
- API 测试：鉴权、越权、分页/错误结构、限流行为。
- UI 测试：主要用户旅程、空状态、错误反馈、金额与时区展示。
- 运维测试：备份恢复、密钥轮换、任务重放和告警。

## 发布前退出条件

没有 Blocker/Critical 未解决安全问题；G1/G2 决策签署；P0 验收用例有执行证据；Docker 与文档匹配；禁用未实现的生产入口。实际通过情况将在实施后记录，不在此预填。
