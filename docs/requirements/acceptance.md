## G1 产品业务规则验收（新增入口）

第三轮产品评审有 [15 条 G1 手工验收](g1-business-acceptance.md)，验证 FBA/FBM 边界、SKU、折扣/部分退款、费用完整度、防重复计费和成本时点。**G1-AC 不是系统运行通过记录**；实现时仍须将其映射到 Mock / API / UI 的可执行测试。

## G2 架构约束验收入口

新增 [G2-QA-001：16 条约束级评审用例](g2-architecture-acceptance.md)，覆盖租户外键、来源金额、同步原子性、旧 Worker fencing、OpenAPI 错误语义等。**所有用例仍为设计规格，未执行，不能视为通过。**

## 各层测试

- 领域测试：SKU 映射、状态迁移、利润公式、成本有效区间。
- 适配器契约测试：相同 Mock 结构，Amazon DTO 映射不外泄到领域。
- DB 集成测试：Flyway migrations、唯一键、事务/锁、跨租户拒绝、恢复导入。
- API 测试：鉴权、越权、分页/错误结构、限流行为。
- UI 测试：主要用户旅程、空状态、错误反馈、金额与时区展示。
- 运维测试：备份恢复、密钥轮换、任务重放和告警。

## 发布前退出条件

没有 Blocker/Critical 未解决安全问题；G1/G2 决策签署；P0 验收用例有执行证据；Docker 与文档匹配；禁用未实现的生产入口。实际通过情况将在实施后记录，不在此预填。
