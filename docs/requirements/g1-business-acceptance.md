## 复核流程

1. 两位角色分别核对：运营确认状态与库存、财务确认金额及费用分类。
2. 按案例逐条选择 `通过 / 有条件通过 / 不通过 / 暂不能判断`，**没有人签字则全部为“未审核”**。
3. 发现异议，记入 [DEC-001](../governance/decision-register.md) 关联原因，不直接改 API 或表结构。
4. G1 产品负责人认可核心项后，G2 再将业务规则落实到物理数据字段和真实 API 操作的合法可用性。
