## 通用字段与交互要求

- 列表必须支持租户安全的分页、过滤、排序；导出遵守当前用户权限。
- 后台写操作应具有请求 ID、审计人、发生时间、变更前后关键字段。
- API 异常向前端返回结构化错误码与可定位任务 ID，绝不透出 token。
- 各类同步视图必须显示 `sourceUpdatedAt` 与 `lastSyncedAt`，区分平台时间和 ERP 获得时间。
- 金额展示「币种 + 金额 + 计算口径」；多币种汇总需要用户选择折算币种。

## 优先级策略

按「卖家可连通 → 数据可同步 → 记录可信 → 指标可解释 → 安全可运维」排序。没有上游数据与验收标准的下游页面不得先宣称功能完成。
