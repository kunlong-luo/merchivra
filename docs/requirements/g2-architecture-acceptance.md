## G2 必须提供的评审证据

1. 表清单与物理约束：哪些唯一键实际受源字段保证？是否能用 composite foreign keys 拦截串租户？
2. 关键同步故障注入：事务、任务锁、游标过期、消息重复和来源延迟如何恢复？
3. API schema：路径、金额字符串、分页游标、不暴露源 token、错误码/鉴权契约。
4. 权限负例：租户、店铺、角色和 Worker 的组合测试设计。
5. 真实 Amazon 角色/字段问题必须有已审批试点记录；无法取得时使用 Mock 模式，不得宣称完成。

当前所有 G2-AC 条目均为 **未执行**。它们只用于评估设计是否足够具体，不能用文档存在替代运行测试。
