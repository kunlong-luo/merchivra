4. **运维/发布 G3**：提供真实目标 PG18 离站备份、WAL/PITR/RPO/RTO、外部 Alertmanager 投递/ACK、部署/回滚和应急方案的非敏感审批引用。CI V142/V146 隔离证据只允许作为准备工作。
